# Unity 分阶段跳过

- 教学/准备页右上角“跳过教学 / 准备”：直接开始当前组，教学和准备时间不计入有效训练。
- 训练页“跳过本组”：跳过当前组，进入下一组的教学/准备；同一动作还有剩余组时继续该动作。最后一组跳过后结束整课。
- 休息页“跳过休息”：立即进入下一组准备，最后 5 秒仍显示按钮；暂停休息时也可主动跳过。
- 独立热身动作属于训练组，可用“跳过本组”；教学/准备的跳过不会把一个热身动作算作完成。

Flutter 是嵌入模式阶段权威，新增 `skip_preparation`、`skip_set` 控制事件。跳过组写入 SQLite `skipped` 状态与 `set_skipped` 事件，不增加完成组数、不写入已完成组证据；最终日志保留完成组数/计划组数，存在未完成组时标记未全部完成（当前模型 aborted）。重复事件沿用事件去重，ready 状态忽略跳过本组。

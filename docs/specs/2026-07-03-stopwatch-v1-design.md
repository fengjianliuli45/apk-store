## 1. 产品定位

AI 健身教练。像秒表一样简单——打开即练。核心差异化：**同道鼓励闭环 + 段位晋升系统**。

## 2. 视觉系统

| 属性 | 值 |
|------|-----|
| 基调 | 冷白金属（银白渐变，#EDEFF2→#E8EAED） |
| 按钮 | 圆形浅浮雕 · 「开始」 |
| 按钮颜色 | 随段位变化（白→黄→绿→蓝→红→金→暗金） |
| 边缘处理 | 磨砂玻璃透明过渡 |
| 配色 | 统一暖瓷白贯穿全 App |

## 3. 段位系统（跆拳道腰带制）

| 段位 | 触发条件 | 按钮色 |
|------|----------|--------|
| 白带 | 初次设定目标 | 白色浮雕 |
| 黄带 | 第 1 次重新评估 | 暖金色微光 |
| 绿带 | 第 2 次评估 | 浅绿色 |
| 蓝带 | 第 3 次评估 | 天蓝色 |
| 红带 | 第 4 次评估 | 深红色 |

| 暗金 | 持续达成新目标 | 暗金色（秦黑为尊） |

### 3.1 升段动画

三层内容交替播放，总时长约 14-16 秒（可跳过）：

| 层 | 内容 | 来源 |
|----|------|------|
| 弹幕 | 同道鼓励语 + 幽默健身梗 + 历史数据 | 系统预设库 + 真实数据 |
| 社区高赞动画 | 点赞前 3 同道自拍/漫画 → 2s 短动画 | 社区数据 |
| 我喜欢的内容 | 用户点赞/收藏的动态 → 2s 短动画 | 个人数据 |

**动画时序：**
```
弹幕(2s) → 社区动画(2s) → 弹幕(2s) → 我喜欢(2s) → 弹幕(2s)
    ↓
全部内容加速收缩
    ↓
💧 汇聚成汗滴 → 滴落「开始」按钮 → 涟漪扩散
    ↓
当前段位颜色从汗水落点向外褪去
    ↓
新段位颜色从同一点注入 → 晕染整个按钮（2s）
    ↓
按钮微光浮现 → 返回主屏
```

**兜底**：无社区/个人数据时，纯弹幕 + 预设幽默动画。

## 4. 屏幕流

### 4.0 账户系统

- Firebase Auth（Email + Password）
- 注册/登录邮箱 + 密码
- 新用户 → 跳转入门问答
- 老用户 → 直接进入主屏
- 用户数据（段位/身体参数/训练历史）存 Firestore

### 4.1 入门（首次/重新评估时）

- AI 分步问答引导
- 一次一个问题（聊天式）
- 采集：性别、年龄、身高、体重、体脂率、训练目标（减脂/增肌/塑形）、场景（居家/街头/健身房）
- 采集完毕 → AI 生成训练计划

### 4.2 计划概览

- 环形总览：总组数 / 预计用时 / 消耗估算
- 人体肌肉模型：本次训练涉及肌肉群标红，点击查看对应动作
- 动作卡片列表（可滚动）
- 「确认开始」按钮

> 触发：主屏点击「开始」后展示。每次训练前确认计划。

### 4.3 主屏

- 极简：仅圆形浮雕「开始」按钮居中
- 暖瓷白背景留白
- 按钮颜色反映当前段位

### 4.4 训练中

布局（从上到下）：
- **头顶**：当前动作名称（大字，如「深蹲」）
- **屏幕正中央**：**3D 柯基**循环演示当前动作（固定正面机位，见 `2026-07-15-stopwatch-3d-coach-design.md`）
- **柯基下方**：组数 / 次数副标题
- **底部**：训练计时 + 「完成本组」按钮

**分层揭晓**：每组练完才显示下一组内容，保持专注和悬念。

### 4.5 组间休息

**主舞台（柯基居中）：**
- **头顶**：休息倒计时（最大字号）
- **中央**：柯基演示 **放松/拉伸** 动作（`stretch` clip）
- **柯基下方**：放松要点文案（如「肩胛放松 · 深呼吸」）
- **倒计时 ≤5 秒**：显示下一动作卡片，柯基 **切换演示下一动作**

**可选 overlay · 同道鼓励**（可跳过，不挡中央柯基）：
- 随机同道自拍 / 鼓励语
- 👍 点赞 + 👥 关注
- 「也拍一张？」→ 📷 自拍 → 发布

跳过鼓励后直接进入上述倒计时 + 柯基教练流。

### 4.6 全部结束

- 🎉 动画庆祝（撒花/礼花）
- 数据总结：总用时 / 完成组数 / 消耗估算
- AI 评语
- 「🥗 解锁饮食」入口按钮

### 4.7 循环

完成阶段训练目标后：
- 重新填写身体参数
- AI 重新生成训练计划
- 触发升段评估

## 5. 饮食模块

### 5.1 拍照

- 全屏相机取景器
- 拍食物 → AI 识别

### 5.2 识别卡片

- 食物名称
- 热量（kcal）
- 蛋白质 / 碳水 / 脂肪（g）
- 确认保存按钮

### 5.3 AI 食谱推荐

- 结合训练目标 + 当日能量缺口 → 推荐下一餐食谱
- 底部「换个菜」按钮 → 手动触发 AI 对话
- AI 对话：用户提需求 → AI 推荐平替 → 确认

### 5.4 能量环

- 消耗 vs 摄入可视化
- 缺口/盈余显示
- 周趋势

### 5.5 饮食日记

- 当日时间线：早餐 / 午餐 / 晚餐 / 零食
- 每餐标注总热量

### 5.6 漫画生成

- 拍完食物 → 可选「生成漫画版」
- 风格：灵宝日记/旅行青蛙
- 生成后发布到同道社交圈

## 6. 同道鼓励闭环

```
完成一组训练

👍 点赞 / 关注

    ↓

```

## 8. 技术栈

- Android：Kotlin + Jetpack Compose
- 账户：Firebase Auth（Email + Password）
- 数据：Firestore（用户数据/训练记录/段位）
- UI 设计：Stitch（Google Cloud MCP）
- AI：DeepSeek / 智谱 GLM（训练计划 + 饮食识别 + 食谱推荐）
- 相机：CameraX
- OTA：gen-hub（channel: stopwatch）
- 发布：GCS + gen-hub API

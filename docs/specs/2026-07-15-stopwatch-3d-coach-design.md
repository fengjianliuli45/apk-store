## 3. 3D 柯基教练（猛兽派对式）

### 3.1 角色：柯基

| 属性 | 规格 |
|------|------|
| 参考 | Party Animals 首角色 **Nemo（柯基）** — 短腿、长身、大耳、橘白配色 |
| 配色 | 橘棕 `#D4893A` + 白胸 `#F8F4EE` |
| 比例 | 身长 > 身高；腿极短；头略大；尾巴蓬松 |
| 气质 | 憨萌、好跟练；表情 2–3 态（眯眼笑 / 憋气 / 放松） |

### 3.2 参考特征（Party Animals → Stopwatch 转译）

| 猛兽派对 | Stopwatch 转译 |
|----------|----------------|
| 矮胖比例、大头小身 | **柯基**：长身短腿，头身可读 |
| 低多边形 + 柔和材质 | 面数预算 ≤8k/角色；圆角法线、无硬边写实皮肤 |
| 物理感、弹性过冲 | 动作带 **squash & stretch**（下蹲压扁、起身拉长 8%） |
| 表情可读 | 眯眼笑 / 鼓腮憋气等 **2–3 种表情状态**，非恐怖谷写实脸 |
| 物理引擎搞笑 | **去掉**打斗物理；保留 **缓动过冲**（非 ragdoll） |
| 明亮可爱 | 橘白柯基 + 冷白金属 UI 背景对比 |

### 3.3 镜头与构图（柯基居中）

**训练中**

```
┌─────────────────────────┐
│                         │
│         深蹲            │  ← 头顶：当前动作名（大字）
│                         │
│        🐕 柯基          │  ← 屏幕正中央（占可视区 ~55%）
│      （循环示范）         │
│                         │
│    第 2/3 组 · ×20      │  ← 柯基下方副标题
│                         │
│        02:34            │  ← 底部：训练计时（次要）
│      [完成本组]          │
└─────────────────────────┘
```

**组间休息**

```
┌─────────────────────────┐
│                         │
│          42             │  ← 头顶：休息倒计时（最大字号）
│                         │
│        🐕 柯基          │  ← 中央：放松/拉伸 clip（stretch）
│    肩胛放松 · 深呼吸     │
│                         │
│  ── 倒计时 ≤5s 时 ──     │
│      下一动作           │
│       俯卧撑            │  ← 卡片 + 柯基切 pushup clip
│     ×15 · 胸部训练      │
│      [跳过休息]          │
└─────────────────────────┘
```

- 机位：正面略俯 8°，**不切镜头**；柯基 anchor 在屏幕几何中心
- 头顶文案层 z-index 高于 canvas，不遮挡柯基面部（文案在上、柯基在中）
- 最后 **5 秒** 规则：`countdown <= 5` → 显示下一动作卡片 + `coachClip` 切到下一动作演示

### 3.4 动作库（MVP）

| exerciseId | 动作 | 动画要点 | 时长 |
|------------|------|----------|------|
| sq | 深蹲 | 膝髋同步、背中立、底部停 0.3s | 3s loop |
| pu | 俯卧撑 | 身体刚性平板、肘约 45° | 3s loop |
| pl | 平板支撑 | 微颤呼吸、核心收紧提示线 | 4s loop |
| lu | 弓步蹲 | 前膝不过脚尖、躯干直立 | 3s loop |
| cr | 卷腹 | 下巴微收、上背离地 | 3s loop |
| jk | 高抬腿 / 波比 | 节奏型循环 | 2.5s loop |
| stretch | **休息放松** | 左右摇摆、耸肩、深呼吸节奏 | 3.2s loop |
| * | 默认 | 通用热身摇摆 | 3s loop |

每组切换动作时 **0.4s crossfade** 到下一 clip，避免硬切。

### 3.5 技术路线（Android）

| 阶段 | 方案 | 产出 |
|------|------|------|
| **P0 预览** | Web `three.js` 原型（`web/coach-3d.js`） | 给设计/产品「看一眼」 |
| **P1 MVP** | **SceneView + Filament** 播放预烘焙 **GLB** 循环动画 | `TrainingScreen` 替换 🏋 占位 |
| **P1 资源** | Blender **柯基** 绑定 → GLB | `assets/coach/corgi_*.glb` |
| **P2** | 单角色多 clip 状态机 + 表情 blend | `CoachAnimator.kt` |
| **不做** | 实时物理 ragdoll、用户自定义角色、商城换装 | scope 外 |

### 3.6 性能预算

- 目标设备：中端 Android，训练/休息页 **≥55fps**
- 单 GLB ≤ 2MB（Draco）
- 同屏仅 1 柯基 + 1 方向光
- 切后台暂停渲染
- **休息屏继续播 3D**（放松教学是核心体验）；同道鼓励卡可叠在休息前 0–8s 可选阶段（v1.1）

### 3.7 休息状态机

```
进入 Rest
  → clip = stretch，头顶 = countdown
  → 每秒 countdown--
  → if countdown <= 5:
        显示 nextExercise 卡片
        clip = nextExercise.coachClip（如 pushup）
  → countdown == 0 → 回到 Training
```

同道鼓励（点赞/自拍）改为 **可选 overlay**，不挡中央柯基；Skip 后直接进入上述倒计时流。

### 3.8 与 AI 计划的关系

- `Exercise.id` 映射 `coachClip`（见上表）
- AI 新增动作时：无匹配 clip → 回退 `default` + 文字要点（`exercise.subtitle`）
- 后续可用 LLM 生成 **要点字幕**（「膝盖别内扣」），叠在教练下方 1 行

## 4. 屏幕流修订

### 4.4 训练中

- **柯基屏幕正中央**循环当前动作
- **头顶**：当前动作名称（如「深蹲」）
- **柯基下**：组数 / 次数副标题
- **底部**：训练计时 + 「完成本组」

### 4.5 组间休息

- **柯基屏幕正中央**演示放松动作（`stretch` clip）
- **头顶**：休息倒计时（最大视觉权重）
- **柯基下**：放松要点（如「肩胛放松 · 深呼吸」）
- **倒计时 ≤5 秒**：弹出下一动作卡片，柯基 **切换为下一动作 clip** 预演
- 同道鼓励可跳过；不强制挡中央教练

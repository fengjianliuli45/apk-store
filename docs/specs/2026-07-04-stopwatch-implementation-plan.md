## Phase 1：项目脚手架

| 任务 | 产出 | 估时 |

| 1.3 接入 Firestore | 用户数据/训练记录/段位 | 1h |
| 1.4 接入 gen-hub OTA | 更新检测 + 下载 | 0.5h |

## Phase 2：Stitch UI 生成

| 任务 | 产出 |

## Phase 3：核心训练流

| 任务 | 产出 |
|------|------|
| 3.1 登录/注册屏 | → 新用户跳入门；老用户跳主屏 |
| 3.2 入门问答 | AI 分步对话 → 生成训练计划 |
| 3.3 计划概览 | 肌肉模型 + 环形总览 + 卡片列表 |
| 3.4 主屏 | 圆形浮雕「开始」按钮（段位色） |
| 3.5 训练中 | 动作演示 + 计时器 + 完成按钮 |
| 3.6 组间鼓励 | 同道自拍 + 点赞 + 自拍回馈 |
| 3.7 组间休息 | 倒计时 + 下一组预览 |
| 3.8 完成页 | 庆祝动画 + 数据总结 + AI 评语 |

## Phase 4：饮食模块

| 任务 | 产出 |
|------|------|
| 4.1 相机取景器 | CameraX 全屏拍照 |
| 4.2 AI 识别卡片 | 食物名 + 热量 + 营养 |
| 4.3 能量环 | 消耗/摄入可视化 |
| 4.4 AI 食谱推荐 | 推荐 + 「换个菜」对话 |
| 4.5 饮食日记 | 当日时间线 |
| 4.6 漫画生成 | 灵宝日记风格 |

## Phase 5：段位系统

| 任务 | 产出 |
|------|------|
| 5.1 段位状态机 | 白→黄→绿→蓝→红→金→暗金 |
| 5.2 按钮颜色映射 | 七色渐变 |
| 5.3 升段动画 | 弹幕 → 汗水 → 褪色重染 |

## Phase 6：集成与发布

| 任务 | 产出 |

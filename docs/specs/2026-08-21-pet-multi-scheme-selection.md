## 1. 创意摘要

现在 3D 教练是**单一柯基**角色（猛兽派对式）。少主想把**多种宠物设计思路各做成方案**，全部打包进 **Mate 版本**一起发，最后靠**用户数据选出最受欢迎的**那个，胜出者转正。

> 核心：不赌单一设计 → 让用户用脚投票 → 用发布做 A/B 选型。

## 2. 记录要点（帕西初步整理，未展开）

### 2.1 方案差异度
- 别做「同款换皮」，否则选不出来
- 倾向按**性格/气质**分（而非纯外观）：憨萌柯基（现）/ 高冷猫 / 热血柴犬 / 机械系等，各配不同训练陪伴风格（鼓励式 / 毒舌式 / 安静式）

### 2.2 度量「最受欢迎」（关键）
- 不只一次「选哪个」投票
- 建议多信号综合：新手引导选宠（显式）+ 训练完成/停留率（行为）+ 换宠率（换成别宠 = 不满意）
- 用**保留率**而非「首次选择率」定赢家

### 2.3 成本提醒
- 每 3D 角色 = Blender 建模 + 绑定 + 8 动作 GLB + 状态机，非换贴图
- 建议 Mate 先放 **2–3 个**验证机制；或低成本差异化（共享动作库 + 换色/表情/话术）

### 2.4 与「免费试用 1 个月」衔接
- 试用期当「选型期」：免费用户贡献数据，1 个月后按最受欢迎定正式角色 + 季卡绑定（呼应智能戒指周边预告）

## 4. 追加思路（2026-08-21 · 少主补充三条，仅记录未展开）

1. **烦恼导向的 Agent 宠物**：收集用户目前的烦恼 → 设计真正能帮用户解决问题的宠物 agent（例：视频剪辑等具体任务），不止训练陪伴。
2. **词条程序化生成 · 独一无二**：无数词条组合成独特宠物（类比《无主之地 Borderlands》号称无数种枪支，每个独一无二）。
3. **宠物成长绑定健身数据**：宠物随用户一起成长——用户代谢水平 / 增肌速度 / 减肥速度生成独特宠物，为相同体质的人提供参考。

> ⚠️ 备注：思路 2（词条无穷生成）与「打包几个方案让用户选最受欢迎」在机制上可能不同向（生成式 vs 有限候选选型），待后续讨论时厘清。

# Unity 浅灰无边界场地

用户确认以无边界摄影棚替换封闭房间。本次不复制未经查看的 Zing 画面，按确认的浅灰场地、柔和接触阴影方案实现。

## 实现

- StudioShowroomBuilder 移除可见墙面、天花板和墙角，改为 200×200 的连续哑光浅灰地面。当前固定俯视摄像机的视锥内不会出现地面边缘，形成无边界视觉。
- 保留碰撞地面顶面 y=0，地面接收教练阴影；提高环境光、降低主光强度和阴影强度，保留轻柔落地阴影。
- 正面/侧面摄像机仍为固定位置直接切换，没有修改动作或引擎处方。
- 本方案面向当前两个固定视角，不是可任意漫游的无限世界。未来若增加仰视或自由镜头需另行设计背景。
